## 1. 範圍

承辦人在同一個畫面看到 30 桌的安排狀況，把人拖到桌次就完成入座；當天工作人員一眼找到某人坐哪一桌。

| 編號 | 功能 | 說明 |
|---|---|---|
| SEAT-01 | 座位圖 | 30 桌依場地排列，可縮放、適合視窗、平移 |
| SEAT-02 | 展開與收合 | 全部切換「只看桌號」與「看到名單」 |
| SEAT-03 | 拖移入座 | 從人員面板拖到桌次、桌次之間搬移、拖回面板移出、桌內調整順序；「入座…」「移至其他桌次…」是替代操作 |
| SEAT-04 | 桌次詳情 | 查看與編輯一桌：備註名稱、名單順序、加入人員、移出、清空 |
| SEAT-05 | 桌次標示 | 桌號、部門（自動）、備註名稱（手動）、人數、兒童椅、素食 |
| SEAT-06 | 人員面板 | 未入座與全部參與人員，第二行顯示部門與組別，可搜尋、篩選，從這裡拖移或用「入座…」；工作人員只在「全部」 |
| SEAT-07 | 找人 | 搜尋後按桌次，在座位圖標示那一桌 |
| SEAT-08 | 復原 | 每次入座、搬移、移出、調整順序、清空、對調、加入人員、工作人員進出後，可復原最近一次 |
| SEAT-09 | 拖移調換桌次 | 拖桌次的把手到另一桌，兩桌的名單與備註名稱整組對調；桌次詳情的「調換桌次…」是替代操作 |
| SEAT-11 | 工作人員桌 | 座位圖右上角一張不編號的桌，最多 10 位，只放員工；可拖進拖出、點開看名單與加入人員 |

**本文件包含：** 座位安排頁的頁首與統計列、座位圖、人員面板、桌次詳情（含調換桌次、加入人員、清空確認）、選擇桌次對話框（參與人員頁的「入座…」「移至其他桌次…」也用它）、工作人員桌與工作人員桌詳情、復原。

## 2. 畫面

本節寫明組合方式、尺寸與 token。文字沒寫到的視覺細節（圖示、間距、行高）依 `ui-design-system/source-reference/html/seating.html` 與 `prototype/prototype.css`；行為一律以本文件為準。元件、token 與字級的定義見 `README.md` 的設計規範。

### 2.1 座位圖

座位圖是設計系統沒有的畫面，以下只用既有 token 組合。

#### 2.1.1 頁首

| 部位 | 做法 |
|---|---|
| 版面 | 頁面全寬，由上到下是頁首與工作區 |
| H1 | 「座位安排」，`Text-2xl/Bold`；H1 下不放頁面說明 |
| 統計列 | 緊接在 H1 右邊的一行文字，和標題對齊基線；寬度不夠時換行到 H1 下方。數字用 `Text-sm/Medium`，其餘用 `Text-xs/Regular`，項目之間用「・」分隔，不做 Stat Card。內容見 SEAT-R75 |
| 右側按鈕 | 依序是「新增人員」Button `primary`，開啟新增人員對話框（見 `participants.md`）；「匯出座位表」Button `outline`（見 `export.md`）；「發布」Button `outline`，開啟發布對話框，只有編輯者看得到（見 `permissions.md`）。只能檢視時只有「匯出座位表」（SEAT-R90） |

#### 2.1.2 工作區

| 部位 | 做法 |
|---|---|
| 版面 | 人員面板（280 px）在左、座位圖在右，兩者高度填滿視窗剩餘的高度 |
| 人員面板 | 可收合，收合後座位圖佔滿寬度（2.2） |
| 座位圖 | 上方是工具列，下方是座位圖區（場地圖） |
| 桌次詳情 | 從座位圖區右側浮出（360 px），不是 modal，座位圖其他部分仍可操作（2.3） |

#### 2.1.3 工具列

| 項目 | 元件 | 說明 |
|---|---|---|
| 顯示人員面板 | Button `outline` | 只在人員面板收合時出現 |
| 縮小、放大 | Icon Button `outline` | 縮放比例以文字「{n}%」顯示在縮小與放大之間 |
| 適合視窗 | Icon Button `outline` | 回到自動適合（SEAT-R64） |
| 全部展開／全部收合 | Button `outline` | 文字依目前狀態切換（SEAT-R69） |
| 自動排座 | Button `outline`，靠右 | 開啟自動排座對話框，之後的流程見 `auto-arrange.md`；手機也有；只能檢視時不顯示（SEAT-R90） |

Icon Button 的 Tooltip 與無障礙名稱用按鈕文案（縮小、放大、適合視窗）。

#### 2.1.4 座位圖區與排列

| 部位 | 做法 |
|---|---|
| 座位圖區 | 底色 `--background`、邊框 `--border`、圓角 `--radius-xl`；內容依縮放比例繪製，只在區內捲動與平移，整頁不可水平捲動 |
| 置中 | 場地圖比座位圖區窄時水平置中；打開桌次詳情時，在沒被詳情蓋住的區域置中 |
| 地標 | 舞台、領獎區、控台、出入口：底色 `--muted`、文字 `--muted-foreground`、圓角 `--radius-lg`，只標示位置，不可操作 |
| 地標位置 | 上方由左到右：領獎區（A 外、A 中兩列上方）、舞台（A 內、B 內兩列上方）、控台（B 中、B 外兩列上方）；下方中間是出入口 |
| 桌次 | 舞台在上、出入口在下，左右各三列，相鄰的列錯開半格；主桌（A1、B1 桌）最靠近舞台 |
| 工作人員桌 | 右上角控台下方，B 區外側列最上面的空位（2.5） |

#### 2.1.5 桌次（收合）

預設狀態。

| 部位 | 做法 |
|---|---|
| 外形 | 直徑 88 px 的圓形，底色 `--card`、邊框 `--border`、陰影 `--edge-highlight` 加 `--shadow-xs` |
| 內容（由上到下） | 桌號 `Text-xl/Semi Bold`（只顯示「A1」，不加「桌」）；備註名稱或部門 `Text-xs/Regular`，有備註名稱時顯示備註名稱，沒有時顯示部門，超出時截斷；人數「{已入座}/10」`Text-xs/Medium` |
| Tooltip | 「{備註名稱}・{部門}」，沒有備註名稱時只有「{部門}」 |
| 拖移把手 | 右上角 24 px 的 Icon Button，`grip-vertical` 圖示，底色 `--card`、邊框 `--border`；Tooltip 與無障礙名稱「拖移調換桌次」 |

#### 2.1.6 桌次（精簡顯示）

收合狀態下縮放低於 80% 時改為精簡顯示，縮小後仍看得清楚。

| 部位 | 做法 |
|---|---|
| 內容 | 只放桌號 `Text-4xl/Semi Bold` 與人數 `Text-lg/Medium` |
| 已滿 | 人數改為放大的「已滿」徽章：高 28 px、`Text-base/Medium` |
| 超過 | 11、12 位時人數改為放大的「超過」徽章，尺寸同「已滿」，樣式見 2.1.9 |
| 備註名稱與部門 | 不顯示，改由 Tooltip 顯示（內容同 2.1.5） |
| 拖移把手 | 放大為 36 px |

#### 2.1.7 桌次（展開）

按「全部展開」後所有桌次換成名單卡片。

| 部位 | 做法 |
|---|---|
| 外形 | 寬 256 px、高約 220 px 的卡片（D-022），圓角 `--radius-xl`、底色 `--card`、邊框 `--border`、陰影 `--edge-highlight` 加 `--shadow-xs`、內距 `--space-3` |
| 標頭 | 桌號「{桌號} 桌」`Text-xl/Semi Bold`、人數（或「已滿」「超過」徽章）與拖移把手 |
| 標頭下方 | 備註名稱（`Text-sm/Medium`，有才顯示）在上、部門（`Text-xs/Regular`）在下，各一行、超出時截斷 |
| 名單 | 固定 10 列，分兩欄各 5 列（2.1.8）。這一桌有 11、12 位時改為 12 列、兩欄各 6 列，卡片跟著變高；卡片仍不能互相重疊（D-018） |
| 間距 | 卡片之間左右空 12 px（欄距 268 px）、上下空 12 px（同一欄的列距 232 px；有桌次 11、12 位時 258 px），卡片不會互相重疊（D-022）。工作人員桌的展開卡片同一個寬度 |

#### 2.1.8 名單列（展開卡片）

| 部位 | 做法 |
|---|---|
| 高度 | 24 px |
| 座號 | `--muted-foreground` |
| 姓名 | 完整的顯示名稱，`Text-xs/Regular`，要完整顯示，不能被標示擠到截斷 |
| 標示 | 外部貴賓：一個字的 Badge `outline`「賓」；需要兒童椅：Badge `third` 放 `baby` 圖示；素食：Badge `third` 放 `leaf` 圖示。小徽章高 16 px，滑過顯示 Tooltip（貴賓、兒童椅、素食） |
| 不放 | 分機（分機看桌次詳情與工作人員桌詳情）；眷屬不另加徽章（顯示名稱已有「_眷屬」） |
| 空位 | 底色 `--muted`，文字「空位」 |

#### 2.1.9 狀態與互動

| 狀態 | 做法 |
|---|---|
| 空桌 | 邊框改為虛線、桌號用 `--muted-foreground`；部門顯示「空桌」 |
| 已滿 | 10 位時人數改用正向徽章「已滿」（`--status-positive-bg`／`--status-positive-fg`、`check` 圖示） |
| 超過 | 11、12 位時人數改用待處理徽章「超過」（`--status-pending-bg`／`--status-pending-fg`、`triangle-alert` 圖示，D-018） |
| 有備註名稱 | 收合時顯示備註名稱（部門在 Tooltip）；展開時備註名稱放在部門上方 |
| 滑過 | 加強邊框 |
| 鍵盤焦點 | `--shadow-focus-ring` |
| 點擊 | 整個桌次（把手以外）可點擊，開啟桌次詳情 |
| 拖人員到可放置的桌次上 | 邊框 `--primary`、陰影 `--shadow-md` |
| 拖人員到已滿或超過、但還不到 12 位的桌次上 | 和可放置的桌次相同 |
| 拖人員到已有 12 位的桌次上 | 游標 `not-allowed`，不顯示放置樣式 |
| 搜尋標示 | 邊框改為 2 px 的 `--accent`，4 秒後恢復；邊框加粗時內距同步少 1 px，圓形與卡片裡的內容位置、寬度不變（精簡顯示的「已滿」「超過」徽章不會被截斷） |
| 拖移桌次 | 只能從把手拖（游標 `grab`），拖移中的來源桌透明度 0.6；拖到另一桌上時目標桌邊框 `--primary`、陰影 `--shadow-md` |
| 拖移中的人員 | 來源列透明度 0.5；瀏覽器的拖曳影像使用該列 |

#### 2.1.10 頁面狀態

| 狀態 | 做法 |
|---|---|
| 載入 | 座位圖顯示 30 個圓形的 Skeleton；人員面板依人員列的形狀顯示 Skeleton；不顯示文字 |
| 沒有參與人員 | 座位圖照常顯示 30 桌，都是空桌；人員面板顯示空狀態（2.2.5） |
| 系統錯誤 | 依 `README.md` 的通用狀態 |

#### 2.1.11 手機（767 px 以下）

| 部位 | 做法 |
|---|---|
| 切換 | 頁首下方用 Tabs（pill）切換「座位圖」與「人員」，一次只顯示一個 |
| 座位圖 | 預設收合，以適合視窗顯示；雙指縮放與平移依瀏覽器 |
| 工具列 | 和桌面相同，但沒有「顯示人員面板」；「自動排座」也在 |
| 拖移 | 不提供：人員列與名單列不能拖，桌次沒有拖移把手 |
| 替代操作 | 列操作「入座…」「移至其他桌次…」；對調用桌次詳情的「調換桌次…」；工作人員桌用詳情的「加入人員」與列操作「移出工作人員桌」 |
| 桌次詳情 | 改為 Dialog（2.3.6） |

### 2.2 人員面板

不用離開座位圖，就能找到還沒入座的人並拖過去，也能查任何一個人坐哪一桌。

#### 2.2.1 版面

| 部位 | 做法 |
|---|---|
| 位置與寬度 | 座位圖左側，寬 280 px，高度同工作區；底色 `--card`、邊框 `--border` |
| 由上到下 | 面板標題「人員」（`Text-lg/Semi Bold`）與收合鈕；搜尋框；Tabs（pill）；篩選；人員列清單（在面板內捲動） |
| 收合鈕 | Icon Button，Tooltip 與無障礙名稱「隱藏人員面板」 |
| 搜尋框 | Input `sm` 加 `search` 圖示，提示文字「搜尋姓名、分機、部門或單位」 |
| Tabs | Tabs `default`（pill）：「未入座」「全部」，各自顯示人數 |
| 篩選 | 部門、類別兩個 Dropdown Menu `select`，在面板內用 portal；部門可搜尋，搜尋提示「搜尋部門」；第一項「不限」 |
| 不放 | 新增按鈕（新增人員用頁首的按鈕） |

#### 2.2.2 人員列

| 部位 | 做法 |
|---|---|
| 第一行 | 顯示名稱 `Text-sm/Medium` 加徽章：外部貴賓 Badge `outline`「貴賓」；兒童椅、素食用 Badge `third` 的 16 px 小徽章，只放 `baby`、`leaf` 圖示，滑過顯示 Tooltip。不換行，過長時姓名截斷 |
| 第二行 | `Text-xs/Regular`。員工與眷屬顯示「{部門}・{組別}」（眷屬跟著所屬員工），沒有組別時只顯示部門；外部貴賓顯示單位／頭銜。不放分機。一行顯示，部門過長時截斷，組別一定看得到 |
| 第二行右側（只在「全部」分頁） | 已入座：Badge `outline`「{桌號}」，可按下（SEAT-R62）；未入座：待處理徽章「未入座」（`--status-pending-bg`／`--status-pending-fg`、`clock` 圖示）；工作人員：中性徽章「工作人員」（`--muted`／`--muted-foreground`） |
| 拖移 | 整列都能拖，列上不放拖移把手（手機除外） |
| 列操作 | Icon Button 加 Dropdown Menu `action-menu`（依 `README.md` 的列操作選單），項目見 2.2.3 |

#### 2.2.3 列操作

| 人員狀態 | 項目（依序） |
|---|---|
| 未入座的員工 | 入座…／編輯／取消報名 |
| 未入座的眷屬、外部貴賓 | 入座…／編輯／刪除 |
| 已入座的員工 | 移至其他桌次…／移出桌次／編輯／取消報名 |
| 已入座的眷屬、外部貴賓 | 移至其他桌次…／移出桌次／編輯／刪除 |
| 工作人員 | 移出工作人員桌／編輯／取消報名 |

「編輯」「取消報名」「刪除」的流程見 `participants.md`。

#### 2.2.4 放置提示

從桌次或工作人員桌拖移人員時，清單區上方顯示放置提示「放開以移出桌次」（`--primary` 文字、`--primary` 虛線邊框）；拖到清單區上時清單區加上 `--primary` 邊框。

#### 2.2.5 空狀態

空狀態顯示在清單區內，條件見 SEAT-R59，文案見 4.2。

#### 2.2.6 手機

在「人員」分頁滿版顯示；不顯示收合鈕；人員列不能拖，改用列操作。

### 2.3 桌次詳情

處理一桌的細節：改備註名稱、調整順序、補人、移出、清空。

#### 2.3.1 版面

## 3. 規則

### 3.1 桌次與座位

- **SEAT-R01** 座位圖共有 30 桌，桌號 A1～A15、B1～B15（D-019）。使用者不能新增、刪除、拖移桌次，也不能改桌號。
- **SEAT-R02** 每桌標準 10 個座位，最多可以放到 12 位（D-018）。一桌有 10 位時為「已滿」，11、12 位時為「超過」，12 位是上限。只有拖移與「加入人員」可以放進第 11、12 位（SEAT-R88）；自動排座每桌只排到 10 位（`auto-arrange.md`）。
- **SEAT-R03** 桌次依 2.1.4 的桌號與位置排列：舞台在上、出入口在下；A 區 15 桌在左、B 區 15 桌在右，每區外、中、內三列，相鄰的列錯開半格；A1、B1 桌（主桌）最靠近舞台。
- **SEAT-R04** 桌號就是桌次在場地的位置代碼（A1～A15、B1～B15），畫面上用桌號稱呼桌次（D-019）。單獨出現時寫「A1」（收合的桌次、人員面板與參與人員頁的桌次徽章）；標題與句子中寫「A1 桌」（`README.md` 文案規範）。列出桌次的清單（選擇桌次、調換桌次與新增人員的桌次選項、參與人員頁的桌次篩選）依 A1～A15、B1～B15 排列。
- **SEAT-R05** 另有一張工作人員桌，在 B 區外側列最上面（控台下方、B4 桌上方）；不編號、不算在 30 桌裡，標準 10 位、最多 12 位（D-018），只放員工。
- **SEAT-R06** 桌內名單是有順序的清單，順序只是名單順序，不對應實際方位。名單從座號 1 起連續排列，空位列排在名單之後；有人離開時，其他人依原本的順序往前補（見 SEAT-Q01）。

### 3.2 桌次標示

- **SEAT-R07** 部門由名單自動產生：取這一桌員工的部門與眷屬所屬員工的部門，同一個部門只算一次，依人數多到少排列，以「＋」連接，例如「研發一部＋業務部」（人數相同時見 SEAT-Q04）。不能手動修改。
- **SEAT-R08** 外部貴賓不算部門。名單中有外部貴賓時，在部門最後加上「貴賓」；只有外部貴賓時顯示「貴賓」。
- **SEAT-R09** 沒有任何人時，座位圖上的部門顯示「空桌」，桌次詳情顯示「部門：—」。
- **SEAT-R10** 部門依目前的名單與員工名單即時計算：入座、搬移、移出、清空、對調、加入人員、工作人員進出，以及員工名單的部門或眷屬的所屬員工改變後，座位圖、Tooltip、桌次詳情與桌次選項立即顯示新的部門。
- **SEAT-R11** 人數顯示「{已入座}/10」；滿 10 位時改為正向徽章「已滿」，11、12 位時改為待處理徽章「超過」。桌次詳情的副標照實寫人數，例如「11/10 人」。桌次詳情的「兒童椅 {n} 張」「素食 {n} 位」是這一桌標注兒童椅、素食的人數。
- **SEAT-R12** 備註名稱由使用者自由輸入，離開欄位就儲存，並顯示 Sonner「已儲存」；把欄位清空後離開，就移除備註名稱。按欄位下方的常用選項，就把那個選項填入欄位（見 SEAT-Q13）。
- **SEAT-R13** 有備註名稱時，備註名稱顯示在部門上方，部門照常顯示；收合的桌次只放一行，顯示備註名稱，部門改由 Tooltip「{備註名稱}・{部門}」顯示。
- **SEAT-R14** 備註名稱不影響本文件的任何規則（入座、已滿、搬移、對調、工作人員桌）。自動排座如何使用備註名稱見 `auto-arrange.md`。

### 3.3 拖移入座與搬移

- **SEAT-R15** 可以拖的來源：人員面板的人員列（兩個分頁都可以）、展開桌次的名單列、桌次詳情與工作人員桌詳情的名單列、展開的工作人員桌的名單列。空位列不能拖。
- **SEAT-R16** 把人員放在桌次的任一處（收合的圓形、展開卡片上名單列以外的地方、桌次詳情的名單區）就入座，排到名單最後。
- **SEAT-R17** 放在名單的某一列上，被拖的人插入到那一列的位置，原本在那一列與之後的人往後移一列；放在空位列上，排到名單最後。
- **SEAT-R18** 未入座的人入座後，顯示 Sonner「已把 {顯示名稱} 安排到 {桌號} 桌。」與「復原」。
- **SEAT-R19** 已在某一桌的人放到另一桌是搬移：離開原桌，原桌其他人的順序不變；顯示 Sonner「已把 {顯示名稱} 從 {原桌號} 桌移到 {桌號} 桌。」與「復原」，{原桌號} 是原本的桌。
- **SEAT-R20** 目標桌已有 12 位、而且被拖的人不在這一桌時，拖到上面游標顯示 `not-allowed`，不顯示放置樣式；放開後不入座，顯示 Sonner「{桌號} 桌已達 12 位，請先移出一位。」，不帶「復原」，被拖的人留在原處。目標桌已滿或超過但還不到 12 位時，照常入座（SEAT-R88、SEAT-R89）。
- **SEAT-R21** 拖人員到可放置的桌次上時，桌次邊框改為 `--primary`、陰影 `--shadow-md`；來源列透明度 0.5，瀏覽器的拖曳影像使用該列。

### 3.4 選擇桌次

- **SEAT-R22** 列操作「入座…」（未入座的人）與「移至其他桌次…」（已入座的人）開啟選擇桌次對話框；入口有人員面板、桌次詳情與參與人員頁的列操作。工作人員的列操作沒有這兩項。
- **SEAT-R23** 桌次選項依 A1～A15、B1～B15 的順序列出 30 桌，格式「{桌號} 桌（剩 {k} 位）・{備註名稱或部門}」（{k} 是 10 減這一桌人數，最少 0；11、12 位的桌寫「剩 0 位」）：有備註名稱時用備註名稱，沒有時用部門（空桌見 SEAT-Q05）。目前所在的桌次不列出；已滿的桌次停用並標示「已滿」；工作人員桌不列出。
- **SEAT-R24** 沒選桌次就按「確認入座」或「確認移動」，欄位顯示「請選擇桌次。」，對話框不關閉，不入座。
- **SEAT-R25** 確認後，被安排的人排到該桌名單最後，對話框關閉；Sonner 同 SEAT-R18（入座）或 SEAT-R19（搬移）。

### 3.5 移出、清空與加入人員

- **SEAT-R26** 移出桌次的方式：把名單列拖回人員面板的清單區，或用列操作「移出桌次」。移出後變成未入座，原桌其他人的順序不變；顯示 Sonner「已把 {顯示名稱} 移出 {桌號} 桌。」與「復原」。
- **SEAT-R27** 從桌次或工作人員桌拖移人員時，人員面板的清單區顯示放置提示「放開以移出桌次」。
- **SEAT-R28** 移出桌次、清空桌次只改變入座狀態，不刪除人員：人員仍是參與人員，出現在人員面板的「未入座」分頁。
- **SEAT-R29** 桌次詳情的「清空桌次」先以 Alert Dialog 確認。按「清空桌次」後這一桌的人全部變成未入座，備註名稱保留，顯示 Sonner「已清空 {桌號} 桌。」與「復原」；按「取消」不改變（空桌時見 SEAT-Q06）。
- **SEAT-R30** 桌次詳情的「加入人員」開啟對話框，只列未入座的參與人員，不列已入座的人與工作人員；搜尋範圍同人員面板（SEAT-R54）。最多只能勾到這一桌 12 位為止（{k} 是 12 減這一桌的人數，D-018）：已勾到上限再勾時不會勾選，並顯示「最多只能再加入 {k} 位。」。對話框說明的空位只算到 10 位；這一桌已有 10、11 位時說明改為「已滿，最多還可以加入 {k} 位。」。這一桌有 12 位時，桌次詳情的「加入人員」停用。沒有未入座的人時顯示「所有人都已入座。」（已滿時見 SEAT-Q06）。
- **SEAT-R31** 按「加入 {x} 位」後，勾選的人排到名單最後（之間的順序見 SEAT-Q06），顯示 Sonner「已把 {x} 位人員加入 {桌號} 桌。」與「復原」。

### 3.6 調整順序

- **SEAT-R32** 在同一桌內把名單列拖到另一列，只改變順序，人數不變；顯示 Sonner「已調整 {桌號} 桌的座位順序。」與「復原」。可以在展開的桌次與桌次詳情調整（往下移時的落點見 SEAT-Q02）。
- **SEAT-R33** 已滿的桌次也可以在桌內調整順序。
- **SEAT-R34** 工作人員桌的名單依參與人員的預設排序（見 `participants.md`），不能調整順序。

### 3.7 對調桌次

- **SEAT-R35** 拖桌次的把手到另一桌放開，兩桌的名單（含順序）與備註名稱整組對調，桌號與位置不變；顯示 Sonner「已把 {桌號} 桌和 {目標桌號} 桌對調。」與「復原」，{桌號} 是被拖的桌，{目標桌號} 是目標桌。已滿的桌次也可以對調。
- **SEAT-R36** 拖到空桌等於把整桌（名單與備註名稱）搬過去，原本的桌換成目標桌原本的狀態。
- **SEAT-R37** 只能從把手拖整桌（游標 `grab`），拖移中來源桌透明度 0.6，經過另一桌時目標桌邊框 `--primary`、陰影 `--shadow-md`。點桌次本身（把手以外）是開啟桌次詳情；拖人員列到桌次不會對調。
- **SEAT-R38** 把手放到自己身上、工作人員桌、地標、空白處或人員面板，沒有作用，也不顯示 Sonner。
- **SEAT-R39** 桌次詳情的「調換桌次…」是把手的替代操作：對話框依 A1～A15、B1～B15 的順序列出自己以外的 29 桌，格式「{目標桌號} 桌（{人數}/10）・{備註名稱或部門}」（空桌見 SEAT-Q05）；選一桌按「確認對調」，結果同 SEAT-R35；沒選就按，顯示「請選擇桌次。」，對話框不關閉。

### 3.8 工作人員桌

- **SEAT-R40** 放進工作人員桌的方式：從人員面板或其他桌次拖到座位圖上的工作人員桌或工作人員桌詳情的名單、工作人員桌詳情的「加入人員」、人員對話框勾選「工作人員」（見 `participants.md`）。
- **SEAT-R41** 只有員工可以放進來。把眷屬或外部貴賓放進來時不放進，顯示 Sonner「只有員工可以放進工作人員桌。」，人員留在原處（放開前的樣式見 SEAT-Q12）。
- **SEAT-R42** 工作人員桌已有 12 位時，員工拖進來也不放進，顯示 Sonner「工作人員桌已達 12 位，請先移出一位。」；詳情的「加入人員」停用。已有 10、11 位時照常放進（D-018）。人員對話框的「工作人員」勾選框仍到 10 位為止（`participants.md` 的 PPL-R54）。
- **SEAT-R43** 員工放進工作人員桌就成為工作人員，並離開原本的桌次（原桌其他人的順序不變）。Sonner：原本未入座時「已把 {顯示名稱} 放進工作人員桌。」；從桌次拖過來時「已把 {顯示名稱} 從 {桌號} 桌移到工作人員桌。」；都帶「復原」。
- **SEAT-R44** 員工成為工作人員時，他的眷屬不跟著移動，照常坐自己的桌次（未入座的眷屬維持未入座）。眷屬或外部貴賓拖進已有 12 位的工作人員桌時，先依「只放員工」擋下（SEAT-R41 的提示），不顯示 12 位的提示。
- **SEAT-R45** 把工作人員拖到某一桌，就入座那一桌（落點依 SEAT-R16、SEAT-R17），不再是工作人員；顯示 Sonner「已把 {顯示名稱} 從工作人員桌移到 {桌號} 桌。」與「復原」。目標桌已滿時依 SEAT-R20 提示，仍是工作人員。
- **SEAT-R46** 把工作人員拖回人員面板，或用列操作「移出工作人員桌」，就不再是工作人員，變成未入座；顯示 Sonner「已把 {顯示名稱} 移出工作人員桌。」與「復原」。
- **SEAT-R47** 工作人員不算入座統計，也不算未入座：不計入統計列的已入座、總人數與未入座，也不在「未入座」分頁與它的人數裡。自動排座不排工作人員（見 `auto-arrange.md`）。
- **SEAT-R48** 工作人員桌不編號（沒有桌號）、沒有拖移把手、不能對調、沒有備註名稱，也沒有清空桌次。
- **SEAT-R49** 工作人員桌的部門依 SEAT-R07、SEAT-R09 產生，顯示在展開的工作人員桌、Tooltip 與詳情。
- **SEAT-R50** 工作人員桌詳情的「加入人員」開啟對話框，列出還不是工作人員的已報名員工（已入座的也列，不列眷屬與外部貴賓），最多只能勾到工作人員桌 12 位為止，超過時同 SEAT-R30 提示。按「加入 {n} 位」後勾選的人都成為工作人員、離開原本的桌次，顯示 Sonner「已把 {n} 位人員放進工作人員桌。」與「復原」。沒有可加的人時顯示「已報名的員工都在工作人員桌。」
- **SEAT-R51** 已經是工作人員的人放回工作人員桌，沒有作用。

### 3.9 人員面板

- **SEAT-R52** 只列參與人員；員工名單上還沒報名的人不會出現，要先到員工名單加入尾牙。
- **SEAT-R53** 預設顯示「未入座」分頁：未入座、而且不是工作人員的人。「全部」分頁列出所有參與人員，包含工作人員。分頁上的人數分別是兩者的人數，「未入座」的人數不含工作人員（排列順序見 SEAT-Q14）。
- **SEAT-R54** 搜尋範圍是顯示名稱、分機、部門、組別與單位／頭銜；畫面上不顯示分機，但仍可用分機搜尋。
- **SEAT-R55** 篩選有「部門」與「類別」（員工／眷屬／外部貴賓），第一項「不限」；眷屬依所屬員工的部門篩選。搜尋與篩選同時作用，兩個分頁共用，切換分頁時保留（部門選項見 SEAT-Q14）。
- **SEAT-R56** 人員列第二行：員工與眷屬「{部門}・{組別}」，沒有組別時只有「{部門}」；外部貴賓顯示單位／頭銜；不放分機。
- **SEAT-R57** 「全部」分頁每一列的第二行右側，已入座的人顯示「{桌號}」、未入座的人顯示「未入座」、工作人員顯示「工作人員」。
- **SEAT-R58** 列操作依人員狀態顯示 2.2.3 的項目。
- **SEAT-R59** 清單沒有可顯示的人時，依序取第一個符合的空狀態：

  | 條件 | 空狀態 |
  |---|---|
  | 沒有任何參與人員 | 沒有人員 |
  | 在「未入座」分頁有搜尋字，「未入座」沒有符合、「全部」（同樣的搜尋字與篩選）有 1 位符合 | 那一位已入座時「{顯示名稱} 已入座，在 {桌號} 桌。」；是工作人員時「{顯示名稱} 在工作人員桌。」 |
  | 同上，「全部」有 2 位以上符合 | 「未入座裡找不到「{關鍵字}」。」，內文「全部有 {n} 位符合。」 |
  | 有搜尋字，沒有符合 | 搜尋無結果 |
  | 沒有搜尋字、有篩選，沒有符合 | 篩選無結果 |
  | 「未入座」分頁沒有人 | 全部入座 |

- **SEAT-R60** 空狀態的按鈕：「在全部中查看」切到「全部」分頁，保留搜尋字與篩選；「清除搜尋」清空搜尋字；「清除篩選」把篩選都改回「不限」；「前往員工名單」開啟員工名單頁。
- **SEAT-R61** 按收合鈕，人員面板收起，座位圖佔滿寬度，工具列出現「顯示人員面板」；按「顯示人員面板」就恢復。沒有手動開關過時，視窗寬度低於 1024 px 預設收合，1024 px 以上預設顯示。手機用分頁切換，不受影響。

### 3.10 找人

- **SEAT-R62** 按人員列的「{桌號}」徽章，座位圖把那一桌捲到座位圖區內看得到的位置（不被桌次詳情蓋住），並以 2 px 的 `--accent` 邊框標示 4 秒（手機見 SEAT-Q10）。

### 3.11 縮放、展開與檢視

- **SEAT-R63** 縮放範圍 25%–200%；目前比例以「{n}%」顯示在縮小與放大之間（級距見 SEAT-Q07）。
- **SEAT-R64** 「適合視窗」是預設狀態，讓 30 桌全部可見。在適合視窗狀態下，開啟頁面、視窗大小改變、打開或關閉桌次詳情時都重新計算比例。
- **SEAT-R65** 打開桌次詳情時，適合視窗只用沒被詳情蓋住的寬度；用這個寬度算出的比例低於 35% 時，改用整個座位圖區的寬度。
- **SEAT-R66** 縮放與平移的操作：工具列的縮小、放大；按住 Ctrl（Mac 為 ⌘）加滾輪縮放；在空白處拖曳平移；觸控用雙指縮放與平移。
- **SEAT-R67** 場地圖比座位圖區窄時水平置中；打開桌次詳情時，在沒被詳情蓋住的區域置中。只在座位圖區內捲動與平移，整頁不能水平捲動。
- **SEAT-R68** 收合狀態下比例低於 80% 時，桌次改為精簡顯示（2.1.6）；80% 以上恢復一般收合顯示。
- **SEAT-R69** 預設收合。「全部展開」把所有桌次（含工作人員桌）換成名單卡片並把比例放大到 100%，按鈕變成「全部收合」；「全部收合」換回圓形並回到適合視窗。沒有單桌的展開切換，要看一桌的名單就點開桌次詳情。
- **SEAT-R70** 展開狀態、縮放比例與人員面板的收合狀態會記住，下次開啟沿用（範圍見 SEAT-Q09）。縮放比例只記手動縮放的結果；按「適合視窗」就回到自動適合，不再記比例。桌面與手機的比例分開記，桌面的比例不會帶到手機（全部展開的 100% 見 SEAT-Q08）。
- **SEAT-R71** 手動縮放後，視窗大小改變或開關桌次詳情時比例不變，只重新置中。

### 3.12 桌次詳情

- **SEAT-R72** 點擊桌次（收合或展開，把手以外），或用鍵盤聚焦後按 Enter，開啟那一桌的桌次詳情；點擊工作人員桌開啟工作人員桌詳情。
- **SEAT-R73** 桌面的詳情打開時，座位圖與人員面板仍可操作，可以把人員面板的人直接拖進詳情的名單；點另一桌就換成那一桌的詳情；按關閉鈕關閉。
- **SEAT-R74** 詳情的副標、部門、兒童椅、素食與名單在每次操作後立即更新。

### 3.13 統計列

- **SEAT-R75** 統計列「已入座 {n}／{總人數}・未入座 {m}・空位 {k}・已滿 {t} 桌」，有桌次超過 10 位時最後加「・超過 {u} 桌」：{n} 是 30 桌上的人數；{總人數} 是參與人員中不是工作人員的人數；{m} 是 {總人數} 減 {n}；{k} 是 30 桌的空位數，每桌只算到 10 位為止（10 減這一桌人數，超過的桌算 0）；{t} 是 30 桌中 10 位以上的桌數（含超過的桌）；{u} 是 30 桌中 11、12 位的桌數（D-018）。工作人員桌的人與空位都不算。每次操作後立即更新。

### 3.14 復原

- **SEAT-R76** 可以復原的操作：入座、搬移、移出、調整順序、清空、對調、加入人員（桌次與工作人員桌）、放進與移出工作人員桌、自動排座（見 `auto-arrange.md`）。這些操作完成時都顯示 Sonner，帶「復原」按鈕。
- **SEAT-R77** 只能復原最近一次：做了下一個可以復原的操作後，前一個操作就不能再復原（見 SEAT-Q15）。
- **SEAT-R78** 一次復原的範圍：

  | 操作 | 按一次「復原」還原的內容 |
  |---|---|
  | 入座、搬移、移出、調整順序 | 那一位人員回到原本的桌次與座號（或回到未入座），相關桌次的名單順序回到操作前 |
  | 清空桌次 | 整桌的人回到原本的座號 |
  | 對調桌次 | 兩桌的名單、順序與備註名稱回到對調前 |
  | 加入人員到桌次 | 這次加入的全部人員回到未入座 |
  | 放進工作人員桌（含從桌次拖過來） | 不再是工作人員，回到原本的桌次與座號（或未入座） |
  | 從工作人員桌拖到桌次 | 離開那一桌，回到工作人員桌 |
  | 移出工作人員桌 | 回到工作人員桌 |
  | 加入人員到工作人員桌 | 這次加入的全部人員不再是工作人員，各自回到原本的桌次與座號（或未入座） |
  | 自動排座 | 整次自動排座（見 `auto-arrange.md`） |

- **SEAT-R79** 復原後畫面、統計列與詳情立即更新；「復原」的提示文案與儲存依 `README.md`。
- **SEAT-R80** 不能復原：編輯備註名稱（Sonner「已儲存」不帶「復原」），以及新增、編輯、刪除人員、加入尾牙、取消報名（見 `participants.md`、`employees.md`）。

### 3.15 手機與鍵盤

- **SEAT-R81** 767 px 以下用 Tabs（pill）切換「座位圖」與「人員」，一次只顯示一個；座位圖預設收合，以適合視窗顯示（見 SEAT-Q08）。
- **SEAT-R82** 手機不提供拖移：人員列與名單列不能拖，桌次沒有拖移把手。入座、搬移用列操作「入座…」「移至其他桌次…」；對調用桌次詳情的「調換桌次…」；工作人員桌用詳情的「加入人員」與列操作「移出工作人員桌」。
- **SEAT-R83** 手機的桌次詳情與工作人員桌詳情改為 Dialog。
- **SEAT-R84** 只用鍵盤時，桌次可以聚焦（焦點用 `--shadow-focus-ring`）並開啟詳情；入座、搬移、對調用 SEAT-R82 的替代操作；選擇桌次與調換桌次對話框可以只用鍵盤完成（調整順序見 SEAT-Q11）。

### 3.16 儲存與多人衝突

- **SEAT-R85** 入座、搬移、移出、調整順序、清空、對調、加入人員、工作人員進出、備註名稱與復原，都在操作完成時立即儲存，依 `README.md` 更新儲存狀態。
- **SEAT-R86** 別人剛改過資料，使這次操作不能完成時，依 `README.md` 不儲存並重新載入。座位安排有既有提示時用那句提示：從選單入座（SEAT-R23）時桌次被別人坐到 10 位「{桌號} 桌已滿，請先移出一位。」；拖移或「加入人員」時桌次被別人坐到 12 位「{桌號} 桌已達 12 位，請先移出一位。」；工作人員桌被別人放到 12 位「工作人員桌已達 12 位，請先移出一位。」。

### 3.17 頁面狀態

- **SEAT-R87** 載入中，座位圖顯示 30 個圓形的 Skeleton，人員面板依人員列的形狀顯示 Skeleton，不顯示文字。
- **SEAT-R88** 放進第 11、12 位的方式只有兩種：拖移（人員或名單列拖到桌次、工作人員桌），以及桌次詳情、工作人員桌詳情的「加入人員」。選單類的入口維持到 10 位為止：選擇桌次對話框（SEAT-R23）、新增或編輯人員的桌次欄位與「工作人員」勾選框（`participants.md`），10 位以上的桌停用並標示「已滿」。「復原」與「對調桌次」可以回到最多 12 位的狀態（D-018）。
- **SEAT-R89** 拖移或「加入人員」後這一桌超過 10 位時，原本的成功 Sonner 後面加上「這一桌已超過 10 位。」，例如「已把 {顯示名稱} 安排到 {桌號} 桌，這一桌已超過 10 位。」，仍帶「復原」（D-018）。其他成功的 Sonner 也一樣在句尾接這一句，例如「已把 {n} 位人員加入 {桌號} 桌，這一桌已超過 10 位。」「已把 {顯示名稱} 放進工作人員桌，這一桌已超過 10 位。」。是否超過以伺服器回傳的結果為準（畫面上看到的人數可能較舊）。同一桌內調整順序、從超過的桌移出、對調桌次（兩桌只是交換，人數不因這次操作增加）都不加。

### 3.18 只能檢視

- **SEAT-R90** 檢視者開啟時（`README.md` COM-R19、D-021、D-026），座位安排頁的資料和編輯者看到的相同（含桌次詳情第二行的分機、兒童椅與素食），但下列操作隱藏，不是停用：

  | 位置 | 隱藏的操作 | 照常的操作 |
  |---|---|---|
  | 頁首 | 「新增人員」「發布」 | 「匯出座位表」、統計列 |
  | 工具列 | 「自動排座」 | 縮小、放大、適合視窗、全部展開／全部收合、顯示／隱藏人員面板 |
  | 座位圖 | 拖移：桌次沒有拖移把手，展開卡片的名單列不能拖 | 點桌次或用鍵盤開啟詳情、縮放與平移、搜尋標示 |
  | 人員面板 | 人員列不能拖，也不顯示放置提示；列操作按鈕不顯示（項目全都會修改資料） | 搜尋、分頁、篩選、空狀態的按鈕、按「{桌號}」徽章找人（SEAT-R62） |
  | 桌次詳情 | 備註名稱欄位與常用選項、名單說明、名單列的列操作與拖移、「加入人員」「調換桌次…」「清空桌次」 | 標題、副標、部門、兒童椅、素食與名單；備註名稱改以文字（`Text-sm/Medium`）顯示在副標下方，沒有備註名稱時不顯示這一行 |
  | 工作人員桌詳情 | 名單說明、名單列的列操作與拖移、「加入人員」 | 標題、副標、說明、部門與名單 |

  檢視者沒有可以復原的操作，所以不會出現帶「復原」的 Sonner。手機的「座位圖」「人員」分頁照常，桌次詳情仍是 Dialog，只有「關閉」。
