# 自動排座

| 項目 | 內容 |
|---|---|
| 功能編號 | SEAT-10 |
| 入口 | 座位安排頁工具列的「自動排座」 |
| 共用規則 | `docs/spec/README.md`；桌次、桌號、部門標示見 `seating.md` |
| 版本 | v1.4（2026-11-11，自動排座也可以用工具列復原與重做，D-028） |

## 1. 範圍

依員工名單的部門與組別順序，一次把員工與眷屬排進沒有備註名稱的桌。同組的人盡量排在一起，桌桌填滿。可以只排未入座，也可以清空後重排。結果直接套用，可以一次復原。

本檔包含：

- 選範圍的對話框與結果提示。
- 排座規則：誰會被排、排進哪些桌、排列順序、同組在一起的填補方式、拆組、空位不夠時的處理。

不在本檔：

- 拖移入座、桌次詳情、工作人員桌、復原的共用做法：見 `seating.md`。
- 員工名單順序、部門與組別的維護：見 `employees.md`。
- 人員類別、眷屬、工作人員、顯示名稱：見 `participants.md`。

本檔用語：

| 用語 | 定義 |
|---|---|
| 候選人 | 這一次自動排座要排的員工與眷屬（ARR-R03、ARR-R04） |
| 可用的桌 | 放在位置上、沒有備註名稱的桌（ARR-R02）；暫存區的桌與「未放桌」的位置都不是（D-027） |
| 排座單位 | 一起排進同一桌的一群候選人（ARR-R06） |
| 填桌順序 | 自動排座使用位置的先後（「未放桌」的位置跳過，D-027）：B1、A1、B4、B7、B10、B13、B2、B5、B8、B11、B14、B3、B6、B9、B12、B15、A3、A6、A9、A12、A15、A2、A5、A8、A11、A14、A4、A7、A10、A13。桌號改為 A1～B15 前後，這個順序都不變（D-019）；它不是桌號的排列順序 |

## 2. 畫面

### 2.1 入口

- 座位安排頁座位圖工具列右側的「自動排座」按鈕。按鈕樣式見 `README.md` 的元件對應。
- 手機（767 px 以下）的座位圖分頁也有這個按鈕，開同一個對話框。

### 2.2 選範圍的對話框

- Dialog。標題「自動排座」，標題下一段說明。
- 兩個單選項：「只排未入座的 {n} 位」與「清空後重排（有備註名稱的 {k} 桌不動）」。{n}、{k} 的算法見 ARR-R15。
- 沒有未入座的員工與眷屬時，第一個選項停用，並標示「沒有未入座的員工與眷屬」。
- 預設選哪一項見 ARR-Q04。
- 按鈕：「開始排座」（主要按鈕）、「取消」。
- 按「開始排座」：關閉對話框，直接套用結果，不再確認。
- 按「取消」：關閉對話框，座位都不變。

### 2.3 結果提示

- 套用後以 Sonner 顯示排了幾位、排到哪幾桌，帶「復原」按鈕（ARR-R13、ARR-R14）。

### 2.4 手機

- 入口與對話框和桌面相同。
- Dialog 寬度隨視窗縮小，按鈕滿版堆疊，主要按鈕在上（`README.md` 通用狀態）。

## 3. 規則

### 3.1 誰會被排、排進哪些桌

| 編號 | 規則 |
|---|---|
| ARR-R01 | 只排員工與眷屬。外部貴賓一律不排，留給承辦人手動安排。工作人員一律不排，留在工作人員桌。工作人員的眷屬不是工作人員，照常排。 |
| ARR-R02 | 可用的桌是放在位置上、沒有備註名稱的桌，依所在位置的填桌順序使用。有備註名稱的桌（例如主桌、供應商）即使是空桌也不用。工作人員桌、暫存區的桌都不是可用的桌；「未放桌」的位置跳過，不會新增桌（D-027）。 |
| ARR-R03 | 「只排未入座」：候選人是目前未入座的員工與眷屬，不含工作人員，也不含暫存區的桌上的人（D-027：暫存的桌整組先放旁邊，不拆開）。已入座的人都不動，各桌原本的座位順序不變。新排的人接在該桌原本的人後面。從填桌順序最前面、還有空位的可用桌開始填，一桌填滿再下一桌。 |
| ARR-R04 | 「清空後重排」：先把所有可用的桌清空。候選人是這些桌原本的員工與眷屬，加上未入座的員工與眷屬，不含工作人員與暫存區的桌上的人；暫存區的桌不清空（D-027）。原本坐在可用桌的外部貴賓回到未入座，不會被排回去。有備註名稱的桌和桌上的人都不動。 |

### 3.2 排列順序與排座單位

| 編號 | 規則 |
|---|---|
| ARR-R05 | 候選人依下列順序排成一列：①部門：依部門在員工名單順序中第一次出現的先後（ARR-Q05）；②組別：同一部門內，依組別在員工名單順序中第一次出現的先後，沒有組別的人排在該部門最後；③同一組內（或同部門沒有組別的人之間）依員工名單順序；④眷屬緊接在所屬員工後面、同桌相鄰，拆組時也不分開（D-009，見 ARR-R09、ARR-R16），部門與組別跟著所屬員工，人數算在該組。所屬員工不是候選人時（已入座、坐在有備註名稱的桌，或是工作人員），眷屬仍排在所屬員工原本的位置。員工名單順序見 `employees.md`（EMP-R07、EMP-Q09）。 |
| ARR-R06 | 依 ARR-R05 的順序把候選人分成排座單位：①同部門、同組別的候選人（含眷屬）是一個單位，人數含眷屬；②沒有組別的員工，連同他的眷屬是一個單位（1 或 2 人）；③沒有組別、所屬員工不是候選人的眷屬，自己是一個單位。 |

### 3.3 填桌

| 編號 | 規則 |
|---|---|
| ARR-R07 | 依填桌順序逐一處理可用的桌。這一桌還有空位時，看排在最前面的單位：人數不超過這一桌的空位，就整個單位依順序排進這一桌，接著看下一個單位。 |
| ARR-R08 | 最前面的單位人數超過這一桌的空位時，先不排它，改從後面的單位找人數不超過空位的來填：①先找同部門、排在後面的單位，取順序上最近的一個；②同部門找不到，再從後面部門的單位找，取順序上最近的一個。填進去之後回到 ARR-R07，再看最前面的單位。被拿去填的單位從原本的位置移走，其他單位的順序不變。 |
| ARR-R09 | 照 ARR-R08 找不到任何排得進去的單位時，才把最前面的單位拆開：依順序取剛好等於空位數的人，填滿這一桌；其餘的人仍是最前面的單位，到下一張可用的桌再照 ARR-R07～ARR-R09、ARR-R16 處理。清空後重排時下一桌是空的，所以其餘的人坐在下一桌最前面。拆點不可以落在員工和他的眷屬之間（D-009）：照空位數取到的最後一位，如果是後面緊跟著眷屬的員工，這位員工也不排進這一桌，和眷屬一起留在其餘的人最前面、排到下一桌；這一桌因此空出 1 個位子，依 ARR-R16 補位。 |
| ARR-R16 | ARR-R09 空出的 1 個位子，從排在後面的單位找一位單獨的員工補上。單獨的員工是這一次要排的人裡沒有他的眷屬的員工。找的順序：①同部門、排在後面的單位；②找不到再找後面部門的單位。單位依順序找，單位內依人員順序，取第一位符合的人。被拆的那一組剩下的人不在找的範圍內。補上的員工離開原本的單位，那個單位其他人的順序不變。後面的單位都沒有單獨的員工時，這個位子留空，接著處理下一張可用的桌。 |
| ARR-R17 | 自動排座每桌最多只排到 10 位，不使用 `seating.md` SEAT-R02 的第 11、12 位（那是承辦人拖移或「加入人員」時的特例，D-018）。「只排未入座」時，已有 10 位以上的桌算沒有空位，原本的人不動；「清空後重排」依 ARR-R04 清空可用的桌後照常排，每桌最多 10 位；有備註名稱的桌不動，桌上 11、12 位的人也不動。 |
| ARR-R10 | 桌桌填滿，不留空位：一個部門排完剩下的空位，由後面部門的人併桌。排完後，填桌順序在「最後一張有排進人的可用桌」之前的可用桌，全部坐滿 10 人；唯一的例外是 ARR-R16 找不到人補而留下的空位，每次 1 個。 |
| ARR-R11 | 空位不夠時能排多少排多少。可用的桌都坐滿後還沒排到的人（含拆開後剩下的人）留在未入座。 |
| ARR-R12 | 自動排座不改任何桌的備註名稱，也不搬動、新增或刪除桌子（D-027）。有備註名稱的桌，名單與座位順序都不變。工作人員桌與暫存區的桌不變。 |

### 3.4 套用、提示與復原

| 編號 | 規則 |
|---|---|
| ARR-R13 | 按「開始排座」後結果直接套用並立即儲存（COM-R01）。按 Sonner 或工具列的「復原」一次就回到自動排座之前的全部座位（再按工具列的「重做」就回到排好的結果，D-028），包含各桌的座位順序，以及清空後重排移到未入座的外部貴賓。復原的共用做法見 `seating.md`。 |
| ARR-R14 | 套用後的 Sonner：全部排進去時顯示「已把 {n} 位安排到 {k} 桌。」；有人排不下時顯示「已把 {n} 位安排到 {k} 桌，還有 {m} 位排不下，留在未入座。」。{n} 是這一次排進桌次的人數，{k} 是這一次有排進人的桌數，{m} 是排不下的人數。兩種都帶「復原」。只排進一桌時見 ARR-Q03；一位都沒排進去時見 ARR-Q02。 |
| ARR-R15 | 對話框的 {n} 是 ARR-R03 的候選人人數：未入座的員工與眷屬，不含外部貴賓、工作人員與暫存區的桌上的人。
{k} 是有備註名稱的桌數。{n} 為 0 時第一個選項停用。 |

## 5. 驗收條件

### 5.1 小型資料

資料的寫法：

- 姓名都是虛構的。「業1–業7」表示業1、業2…業7，員工名單也依這個順序。
- 「業務部／北區組」表示部門與組別；只寫部門就是沒有組別。
- 眷屬的顯示名稱是「{員工姓名}_眷屬」，例如「業4_眷屬」。
- 沒有特別寫的：列出的人都已報名、都未入座；30 桌都沒有備註名稱、都是空桌；沒有工作人員。
- 例子裡的 B1、A1、B4、B7 桌是填桌順序的前四桌。
