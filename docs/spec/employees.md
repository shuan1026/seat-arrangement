## 1. 範圍

| 編號 | 功能 | 說明 |
|---|---|---|
| EMP-01 | 員工清單與報名狀態 | 公司全部員工，搜尋姓名、英文名、分機、部門、組別，依部門、組別、地區與報名狀態篩選，一眼看到誰還沒報名 |
| EMP-02 | 新增、編輯、刪除員工 | 以對話框維護姓名、英文名、部門、組別、分機、地區、備註，刪除需確認 |
| EMP-03 | 加入尾牙與取消報名 | 單筆加入時可同時加一位眷屬；勾選多筆一次加入；已報名者可取消 |
| EMP-04 | 匯入員工名單 | 以公司通訊錄匯出的 CSV 一次建立或更新員工 |
| EMP-05 | 顯示分機 | 員工名單的分機欄；員工在其他畫面帶分機的規則見 `README.md`「分機與員工的第二行」 |
| EMP-06 | 組別 | 部門之下的分組，選填；員工名單顯示、可搜尋、可篩選組別；自動排座如何使用組別見 `auto-arrange.md` |

- 員工名單是公司全部員工，由承辦人匯入公司通訊錄或手動維護，不和其他系統同步。
- 本檔包含：`/employees` 頁面、新增與編輯員工對話框、刪除員工、從員工名單加入尾牙與取消報名的入口、匯入員工名單對話框與匯入規則。
- 不在本檔：加入尾牙對話框的欄位與規則、取消報名的完整規則（`participants.md`）；座位圖、人員面板與桌次詳情的顯示（`seating.md`）；自動排座的排列（`auto-arrange.md`）；App Shell、儲存狀態、多人衝突、登入、兩種權限與只能檢視的共同做法、通用狀態、分頁文案、列操作選單、員工第二行與分機顯示、設計 token、文案規範與用語（`README.md`）。

## 3. 規則

### 3.1 資料與報名狀態

| 編號 | 規則 |
|---|---|
| EMP-R01 | 每位員工有姓名、英文名、部門、組別、分機、地區、辦公室、備註。姓名與部門必填，其他選填。員工沒有工號。組別是部門之下的分組。辦公室的顯示與編輯見 EMP-Q06。 |
| EMP-R02 | 員工名單是參與人員中「員工」的唯一來源。已報名員工的姓名、部門、組別、分機在員工名單改了之後，參與人員與座位圖立即顯示新資料（見 `participants.md`、`seating.md`）。 |
| EMP-R03 | 報名狀態有三種：「已報名」「未報名」「不參加」（D-014）。員工在參與人員中有對應的人員（含工作人員）就是「已報名」，這一點自動判斷、不能手動修改。沒有對應的人員時，承辦人標記為不參加的是「不參加」（表示員工明確說不來，EMP-R63），其餘是「未報名」（還沒回覆或還沒加入）。 |
| EMP-R04 | 部門清單由員工名單產生，不另外維護：只列目前至少有一位員工的部門。每個部門的組別清單、地區清單也一樣，由員工名單產生。 |
| EMP-R05 | 員工名單只列員工，不顯示眷屬；眷屬到參與人員查看。 |

### 3.2 排列與分頁

| 編號 | 規則 |
|---|---|
| EMP-R06 | 開啟頁面時顯示「全部」分頁。 |
| EMP-R07 | 列依部門、組別排列，和自動排座的順序相同（見 `auto-arrange.md`）：部門依在員工名單順序中首次出現的先後；部門內先依組別，組別依在該部門首次出現的先後，沒有組別的員工排在該部門最後；同組內依員工名單順序。「員工名單順序」的定義見 EMP-Q09。 |
| EMP-R08 | Tabs 的四個分頁帶人數：「全部」是員工總數，等於「未報名」「已報名」「不參加」三者相加。其他三個分頁只列該狀態的員工；「未報名」不含不參加的員工。視窗放不下四個分頁時，在分頁列內水平捲動，不造成整頁水平捲動。 |
| EMP-R09 | 每頁 20 列。超過 7 頁時，頁碼只列第一頁、最後一頁與目前頁附近，中間用省略號，和參與人員相同（見 `participants.md`）。分頁摘要與按鈕文案見 `README.md`「共用文案」。 |
| EMP-R10 | 表格欄位依序為勾選、姓名、部門、組別、分機、地區、報名狀態、備註、列操作。姓名下方顯示英文名，沒有英文名時只顯示姓名。組別、分機、地區沒有值時顯示「—」。姓名（中文那一行）、分機、地區、報名狀態一行顯示、不換行；部門、組別、英文名、備註太長時在欄內換行；欄位放不下時表格在內容面板內左右捲動，不造成整頁水平捲動（D-024）。手機的堆疊卡片不受這條限制。 |

### 3.3 搜尋與篩選

| 編號 | 規則 |
|---|---|
| EMP-R11 | 搜尋比對姓名、英文名、分機、部門與組別，任一欄位包含關鍵字就列出。提示文字不寫英文名（320 px 才不會截斷），但搜尋範圍包含英文名。 |
| EMP-R12 | 篩選有部門、組別、地區三項，選項的第一項都是「不限」。部門與組別篩選可以搜尋。 |
| EMP-R13 | 組別篩選的選項是組別名稱：沒選部門時列出所有部門的組別，依部門順序排列；選了部門時只列那個部門的組別。 |
| EMP-R14 | 換部門篩選時，已選的組別不屬於新部門，就清掉組別篩選。 |
| EMP-R15 | 分頁、搜尋與篩選同時生效：列出的員工要同時符合目前的分頁、關鍵字與每一項篩選。 |
| EMP-R16 | 每一項已套用的篩選以一個徽章顯示，按徽章移除那一項篩選。「清除篩選」一次清掉部門、組別、地區三項篩選，不清搜尋。 |
| EMP-R17 | 空狀態依情況顯示（文案見第 4.1 節）：（1）員工名單沒有任何員工：「沒有員工」，按鈕「匯入員工名單」開啟匯入對話框、「新增員工」開啟新增員工對話框；（2）有關鍵字、沒有篩選，且沒有符合的員工：「搜尋無結果」，按「清除搜尋」清空關鍵字；（3）有篩選、沒有關鍵字，且沒有符合的員工：「篩選無結果」，按「清除篩選」清掉篩選；（4）沒有關鍵字與篩選，「未報名」分頁沒有員工：「沒有未報名」；（5）沒有關鍵字與篩選，「已報名」分頁沒有員工：「還沒有人報名」；（6）沒有關鍵字與篩選，「不參加」分頁沒有員工：「沒有不參加」。同時有關鍵字與篩選時見 EMP-Q08。 |

### 3.4 勾選與一次加入多位

| 編號 | 規則 |
|---|---|
| EMP-R18 | 表格第一欄是勾選框。只有未報名的列能勾；已報名與不參加的列顯示停用的勾選框。 |
| EMP-R19 | 表頭的全選只作用於這一頁：勾選時勾起這一頁所有未報名的列，不勾其他頁的列，也不勾已報名與不參加的列；取消時取消這一頁的勾選。 |
| EMP-R20 | 表頭勾選框的狀態：這一頁能勾的列全部勾選時為勾選；只勾一部分時為不確定狀態；都沒勾時為未勾選。 |
| EMP-R21 | 至少勾選一位時，工具列右側出現「加入尾牙（{n} 位）」，{n} 是勾選的員工數；沒有勾選時不顯示。 |
| EMP-R22 | 按「加入尾牙（{n} 位）」先以 Alert Dialog 確認。按「加入尾牙」：勾選的員工都加入參與人員，只加員工本人、不加眷屬，加入後是未入座；Sonner 顯示「已把 {n} 位員工加入尾牙。」按「取消」：不加入任何人。 |
| EMP-R23 | 員工變成已報名後，勾選框改為停用，不再算在 {n} 裡；所有勾選的員工都報名後，批次按鈕消失。 |
| EMP-R24 | 一次加入多位時，勾選的員工中有人已被別人加入尾牙：這次操作整批不儲存，依 `README.md` 的 COM-R07、COM-R08 重新載入並顯示提示。 |
| EMP-R25 | 勾選框的無障礙名稱：表頭為「全選這一頁未報名的員工」，未報名的列為「勾選 {姓名}」，已報名的列為「{姓名} 已報名」，不參加的列為「{姓名} 不參加」。 |

| EMP-R56 | 員工名單只存檔案中的分機、姓名、英文名、部門、地區、辦公室、組別；手機號碼與代接群組不存。更新既有員工時，這些欄位改成檔案的內容；備註不在檔案裡，維持不變。 |
| EMP-R57 | 已報名員工的資料經匯入更新後，參與人員與座位圖跟著變（同 EMP-R39）。 |
| EMP-R61 | 匯入只新增與更新，不刪除：員工名單裡有、但這次檔案裡沒有的員工（例如已離職的人）保留不變，報名與座位也不變；要移除時由承辦人在員工名單手動刪除（D-011）。 |
| EMP-R62 | 檔案欄位和範本一致的判斷（D-012）：欄名前後的空白忽略；沒有欄名的欄（例如通訊錄匯出檔第一欄的序號）忽略；欄位順序不限；範本中「組別」以外的每個欄名都要有，少任何一個就是不一致（EMP-R48）。檔案沒有「組別」欄時照常匯入：新增的員工沒有組別，既有員工的組別維持不變。 |
| EMP-R58 | 有錯誤的列不匯入，其餘的列照常匯入。姓名有值、部門空白的列是有錯誤的列（部門必填）。其他錯誤情況見 EMP-Q03。 |
| EMP-R59 | 匯入完成顯示「已匯入 {n} 位員工，{m} 筆需要處理。」，{m} 是有錯誤的列數；按「下載錯誤清單」下載這些列。{n} 的算法、{m} 為 0 時的顯示與呈現位置見 EMP-Q03。 |
| EMP-R60 | 按「取消」關閉對話框，不匯入。 |
