# 匯出座位表

| 項目 | 內容 |
|---|---|
| 功能編號 | PLT-03 |
| 入口 | 參與人員頁的「匯出座位表」按鈕；座位安排頁頁首也有同一個按鈕 |
| 共用規則 | `docs/spec/README.md`；桌次、桌號、部門標示見 `seating.md` |
| 版本 | v1.4（2026-11-10，桌號改為 A1～A15、B1～B15 D-019；匯出不受介面配色影響 D-020） |

## 1. 範圍

把全部 30 桌、工作人員與未入座的人匯出成一個 Excel 檔（.xlsx）。版面照承辦人提供的 2025 年座位表，和座位圖一樣：舞台在上、A 區在左、B 區在右，餐廳與現場工作人員可以直接對照場地。檔案在伺服器產生，按下按鈕直接下載，不開對話框。

本檔包含：

- 按鈕、下載、成功與失敗提示。
- 工作表的版面：每一格放什麼、哪些格合併、底色與框線、列印設定。

不在本檔：

- 30 桌的排列、桌號、桌次的部門標示：見 `seating.md`。
- 顯示名稱、參與人員的預設排序、兒童椅、素食、工作人員：見 `participants.md`。

本檔寫法：

- 儲存格用 Excel 位址：欄 A 是第 1 欄、B 是第 2 欄…L 是第 12 欄；列從 1 起算。「G1:G10」表示 G1 到 G10 合併成一格。
- 「↵」表示同一格內的換行。
- 「段」：桌次放在第 1–110 列，每 10 列一段，第 k 段是第 10k−9 到 10k 列，共 11 段。

## 2. 畫面

### 2.1 按鈕

- 參與人員頁頁首的「匯出座位表」。座位安排頁頁首也有，行為相同。
- 按鈕樣式見 `README.md` 的元件對應。

### 2.2 下載

- 按下後直接下載 Excel 檔，不開對話框（EXP-R01）。

### 2.3 成功與失敗提示

- 成功：Sonner「已匯出座位表。」（EXP-R06）
- 失敗：Sonner「匯出座位表失敗，請確認網路連線後再試一次。」（EXP-R07）

## 3. 規則

### 3.1 檔案與下載

| 編號 | 規則 |
|---|---|
| EXP-R01 | 按「匯出座位表」直接下載 Excel 檔，不開對話框。參與人員頁與座位安排頁的按鈕行為相同。 |
| EXP-R02 | 檔案內容是全部 30 桌、工作人員與未入座的人，和頁面上的搜尋、篩選、展開收合、縮放無關。 |
| EXP-R03 | 檔名「座位表_{YYYYMMDD}.xlsx」，日期是匯出當天的台灣日期。例如 2026 年 11 月 10 日匯出，檔名是「座位表_20261110.xlsx」。 |
| EXP-R04 | 檔案只有一個工作表，名稱「座位表」。 |
| EXP-R05 | 列印設定：橫向；寬度縮成一頁，高度不限制頁數。 |
| EXP-R06 | 下載成功時以 Sonner 顯示「已匯出座位表。」 |
| EXP-R07 | 產生或下載失敗時（例如網路中斷、伺服器錯誤）不下載檔案，以 Sonner 顯示「匯出座位表失敗，請確認網路連線後再試一次。」登入已過期不算失敗：不下載，依 `README.md` 的 AUTH-R07 回到登入頁並顯示「登入已過期。」（D-016）。 |

### 3.4 標題格、名單格與圖例

| 編號 | 規則 |
|---|---|
| EXP-R12 | 桌次標題格依序分行寫：「{桌號} 桌」、備註名稱、部門、「({人數})」。沒有備註名稱時省略那一行，不留空行。部門依 `seating.md` 的桌次部門標示（員工與眷屬的部門依人數多到少以「＋」連接；有外部貴賓時最後加「貴賓」；只有貴賓時為「貴賓」）；沒有人時寫「空桌」。人數是這一桌已入座的人數，含外部貴賓，用半形括號。 |
| EXP-R13 | 名單格寫顯示名稱（眷屬為「{員工姓名}_眷屬」）。需要兒童椅的人在名字後面加「(+兒童椅)」，素食的人加「(素食)」；兩項都有時寫成「{顯示名稱}(+兒童椅)(素食)」。半形括號，中間沒有空白。外部貴賓不加文字，只用底色。本條適用於桌次、工作人員與未入座的所有名單格。 |
| EXP-R14 | 名單格依人員標底色：需要兒童椅、素食、外部貴賓各一種。一個人有好幾項時，依兒童椅、素食、貴賓的順序取第一個。例如素食的外部貴賓用素食的底色；需要兒童椅又素食的貴賓用兒童椅的底色。三項都沒有的人不加底色。 |
| EXP-R15 | 圖例：A3「貴賓」、A4「兒童椅」、A5「素食」，各用 EXP-R14 對應的底色。A 欄其他格空白。 |

### 3.5 工作人員與未入座

| 編號 | 規則 |
|---|---|
| EXP-R16 | 工作人員區塊在右上角：K1 是標題格，寫「工作人員」↵「({人數})」；名單在 L 欄，從 L1 起由上往下放。標題格合併 K1 到 K{10 與人數取大者}。沒有工作人員時寫「(0)」，L1–L10 留白。超過十位時往下延伸，例如 12 位時合併 K1:K12，名單放到 L12（EXP-Q03）。 |
| EXP-R17 | 未入座是不在任何一桌、也不是工作人員的參與人員，含外部貴賓。有未入座的人時，第 111 列空白，從第 112 列起放「未入座」區塊。 |
| EXP-R18 | 未入座區塊的標題格在 B 欄，寫「未入座」↵「({人數})」。名單從 C 欄放到 L 欄：每欄十位、一段十欄，排滿一段（100 位）再往下一段。第 i 位（從 1 起算）放在：列＝112＋10×⌊(i−1)÷100⌋＋((i−1) mod 10)；欄＝C 欄往右數 ⌊(i−1)÷10⌋ mod 10 欄（C 欄是第 0 欄）。標題格合併 B112 到 B{111＋10×段數}，段數＝⌈人數÷100⌉。 |
| EXP-R19 | 沒有未入座的人時不放未入座區塊，第 111 列以下沒有任何內容。 |
| EXP-R20 | 工作人員與未入座的名單依參與人員的預設排序：依部門排列，眷屬緊接在所屬員工後面，外部貴賓排最後。排序細節以 `participants.md` 的 PPL-R20 為準（部門順序與部門內順序見 PPL-Q13）。 |

### 3.6 底色與框線

| 編號 | 規則 |
|---|---|
| EXP-R21 | 匯出一律用淺色主題的色碼，不受使用者選的介面配色影響（D-020）。底色由設計系統的圖表類別色調淡而來：貴賓 `--chart-cat-2`、兒童椅 `--chart-cat-4`、素食 `--chart-cat-5`。標題格（桌次、工作人員、未入座）用 `--muted`。Excel 只能存固定色碼，所以每一種底色換算成一個固定色碼，並註明對應的 token；同一種用途在整個工作表用同一個色碼，三種名單底色互不相同（調淡的比例見 EXP-Q04）。 |
| EXP-R22 | 框線用 `--semantic-border`。每一桌的標題格與十格名單格都畫框線，空位也畫。工作人員區塊、未入座區塊與圖例的框線見 EXP-Q05。 |
| EXP-R23 | 有桌次 11、12 位（`seating.md` SEAT-R02，D-018）時，只有這一桌所在的那一段改為十二列：這一段每一桌的標題格合併十二列，名單格放第 1–12 位，空位留白、照樣畫框線；其他段維持十列。每多一段改為十二列，下面所有的列（含之後的段、第 111 列的空白列與未入座區塊的起始列）都往下移兩列。標題格的人數照實寫，例如「(11)」，不另加底色。工作人員區塊（K、L 欄）不受段的移動影響，照 EXP-R16；未入座區塊的標題格與合併範圍跟著往下移。沒有桌次超過 10 位時，版面和本檔其他規則完全相同。 |
