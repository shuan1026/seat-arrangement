## 1. 範圍

參與人員是報名尾牙的員工、他們的眷屬與外部貴賓，也是座位安排的對象。本檔定義下列功能：

| 編號 | 功能 | 本檔內容 |
|---|---|---|
| PPL-01 | 參與人員清單 | 搜尋（含分機），依類別、部門、入座狀態（含工作人員）與桌次篩選 |
| PPL-02 | 新增、編輯、移除參與人員 | 以對話框維護；員工用「取消報名」移除，眷屬與外部貴賓用「刪除」，都需確認 |
| PPL-03 | 人員類別 | 員工（必須來自員工名單）、眷屬、外部貴賓；一位員工最多一位眷屬，顯示為「員工姓名_眷屬」 |
| PPL-04 | 兒童椅 | 任何參與人員都可標注需要兒童椅 |
| PPL-05 | 匯入參與人員 | 上傳 Google 表單尾牙報名表的原始檔案，一次加入報名參加的員工與眷屬，以名字與部門對應員工名單（D-010） |
| PPL-06 | 素食 | 任何參與人員都可標注素食 |
| PPL-07 | 工作人員 | 報名的員工可以標為工作人員，放在工作人員桌、不佔 30 桌的座位 |
| EMP-03（部分） | 加入尾牙 | 從員工名單單筆「加入尾牙」時開啟的對話框，以及員工成為參與人員的規則 |

不在本檔：

- 員工名單的欄位、新增編輯刪除員工、匯入通訊錄、報名狀態與勾選多位的畫面：`employees.md`。
- 選擇桌次對話框、入座、搬移、移出與復原、桌次詳情、工作人員桌的版面與操作：`seating.md`。本檔只寫參與人員頁上的入口，以及「工作人員」勾選對參與人員的影響。
- 自動排座：`auto-arrange.md`。
- 匯出座位表：`export.md`。本檔只寫按鈕位置。
- App Shell、儲存狀態、多人衝突、登入、三種身分與檢視者的共同做法、通用狀態與分頁文案、列操作選單、員工第二行與分機顯示、設計 token、文案規範、用語：`README.md`。

## 2. 畫面

### 2.1 參與人員頁

**目的：** 一次看完所有報名的人，維護參與人員，確認每個人有沒有入座。

**版面：** Data Management Pattern，內容全寬，不加頁面光暈。由上到下：

1. 頁首：左邊是 H1「參與人員」與頁面說明；右邊依序是「新增人員」（Button `primary`）、「匯入參與人員」（Button `outline`）、「匯出座位表」（Button `outline`）。只能檢視時只有「匯出座位表」（PPL-R86）。
2. 工具列：搜尋（Input `sm` 加 `search` 圖示）在最前面，其後依序是類別、部門、入座狀態、桌次四個篩選（Dropdown Menu `select`，用 portal 浮出，不靠 `z-index`）。
3. 已套用的篩選：有篩選時出現在工具列下方，每一項是 Badge `outline` 按鈕，最後是「清除篩選」（Button `link`）。
4. 表格：依設計系統 Data Management 的 Table Rules 與 Scrollbar；最右一欄是列操作（Icon Button 加 Dropdown Menu `action-menu`，不顯示勾選狀態）。
5. 分頁：在表格下方，左邊是摘要，右邊是頁碼與上一頁、下一頁。文案見 `README.md`。

**篩選：**

| 篩選 | 選項 | 可搜尋 |
|---|---|---|
| 類別 | 不限／員工／眷屬／外部貴賓 | 否 |
| 部門 | 不限，以及員工名單上的部門 | 是，提示「搜尋部門」 |
| 入座狀態 | 不限／已入座／未入座／工作人員 | 否 |
| 桌次 | 不限／A1～A15、B1～B15（依這個順序） | 是，提示「搜尋桌號」，例如輸入「A1」 |

**表格欄位：**

| 欄位 | 內容 |
|---|---|
| 顯示名稱 | {顯示名稱}；外部貴賓後面加 Badge `outline`「貴賓」。一行顯示，不換行。兒童椅與素食不標在這裡，看「標示」欄 |
| 類別 | 員工／眷屬（{稱謂}）／外部貴賓；眷屬沒填稱謂時只顯示「眷屬」 |
| 換行 | 顯示名稱、類別、分機、標示、桌次一行顯示、不換行；部門或單位、備註太長時在欄內換行；欄位放不下時表格在內容面板內左右捲動，不造成整頁水平捲動（D-024）。手機的堆疊卡片不受這條限制 |
| 部門或單位 | 員工：員工名單上的部門；眷屬：所屬員工的部門；外部貴賓：單位／頭銜 |
| 分機 | 員工：{分機}；眷屬、外部貴賓與沒有分機的員工：「—」 |
| 標示 | 需要兒童椅：Badge `third`「兒童椅」（`baby` 圖示）；素食：Badge `third`「素食」（`leaf` 圖示）；兩項都有就並排；都沒有：「—」 |
| 桌次 | 已入座：Badge `outline`「{桌號}」，可按下；未入座：待處理狀態徽章「未入座」（`clock` 圖示）；工作人員：中性狀態徽章「工作人員」；在暫存區的桌上：Badge `outline`「暫存」，可按下（PPL-R33，D-027） |
| 備註 | {備註} |
| 列操作 | Icon Button，無障礙名稱「更多操作」；選單項目見第 2.2 節 |

**狀態：**

| 狀態 | 做法 |
|---|---|
| 載入 | 依表格形狀顯示 Skeleton，不顯示文字 |
| 空：沒有人員 | 還沒有任何參與人員時，在內容面板內顯示圖示、標題、內文與「前往員工名單」「新增人員」兩個按鈕 |
| 空：搜尋無結果 | 標題與「清除搜尋」 |
| 空：篩選無結果 | 標題與「清除篩選」 |
| 錯誤 | 資料載入失敗時，顯示 `README.md` 的系統錯誤文案與「再試一次」 |
| 不可操作 | 工作人員的列操作沒有入座相關的項目（第 2.2 節）。只能檢視時，會修改資料的按鈕與列操作都不顯示（PPL-R86） |

空狀態的圖示後方用 `--glow-empty`，其他做法見 `README.md`。

**手機（767 px 以下）：**

- 工具列的項目各自滿版，依序堆疊：搜尋、類別、部門、入座狀態、桌次。頁首三個按鈕的位置見待確認 PPL-Q17。
- 表格改為堆疊卡片，每張卡片顯示顯示名稱、類別、部門或單位、分機、標示、桌次，不顯示備註；卡片保留列操作。
- 整頁不可水平捲動。

### 2.2 列操作與確認對話框

列操作的項目依類別與入座狀態決定：

| 人員 | 未入座 | 已入座 |
|---|---|---|
| 員工 | 編輯／入座…／取消報名 | 編輯／移至其他桌次…／移出桌次／取消報名 |
| 員工（工作人員） | 編輯／取消報名 | — |
| 眷屬、外部貴賓 | 編輯／入座…／刪除 | 編輯／移至其他桌次…／移出桌次／刪除 |

在暫存區的桌上的人算未入座（`seating.md` SEAT-R94，D-027），列操作多一項「移出桌次」：員工是「編輯／入座…／移出桌次／取消報名」，眷屬、外部貴賓是「編輯／入座…／移出桌次／刪除」。「移出桌次」讓他離開暫存的桌，Sonner 顯示「已把 {顯示名稱} 移出暫存區的桌。」並帶「復原」。

「取消報名」與「刪除」是危險樣式的選單項目。

**確認對話框：** Alert Dialog，標題與內文寫明後果，確認鈕用 Button `destructive-primary`。桌面取消在左、確認在右；手機按鈕滿版堆疊，確認在上。

- 取消報名：標題、內文與按鈕「確認取消報名」「返回」，見第 4.1 節。
- 刪除：標題、內文與按鈕「刪除人員」「取消」，見第 4.1 節。

### 2.4 從員工名單加入尾牙

員工名單的列操作「加入尾牙」開啟第 2.3 節的新增人員對話框，差別如下：

- 標題仍是「新增人員」。
- 類別固定為「員工」，欄位停用。
- 員工欄位已帶入這位員工，停用，不能更改。
- 其餘欄位（需要兒童椅、素食、工作人員、同時加一位眷屬、備註、桌次）和新增員工相同。
- 主要按鈕是「加入尾牙」，次要按鈕是「取消」。

勾選多位一次加入的畫面與確認對話框在員工名單頁，見 `employees.md`。

### 2.5 匯入參與人員對話框

**要上傳的檔案：** Google 表單尾牙報名表的回覆匯出成 CSV 的原始檔案，不用修改內容（D-010）。系統讀取的欄位見 PPL-R66。

## 3. 規則

### 3.1 類別與資料

- **PPL-R01** 參與人員分三類：員工、眷屬、外部貴賓。每位參與人員只屬於一類。
- **PPL-R02** 員工必須對應員工名單中的一位。姓名、部門、組別、分機都讀自員工名單；參與人員只另外記兒童椅、素食、工作人員、備註與桌次。參與人員頁不能修改姓名、部門、分機。
- **PPL-R03** 一位員工在參與人員中最多出現一次。
- **PPL-R04** 眷屬必須有所屬員工，所屬員工必須是已報名的員工。一位員工的眷屬是 0 位或 1 位。
- **PPL-R05** 眷屬不記錄本名。稱謂選填，只給承辦人看；顯示名稱不含稱謂。
- **PPL-R06** 外部貴賓的姓名必填，內容不限，還不知道姓名時可以填「貴賓席」。單位／頭銜選填。外部貴賓沒有部門與分機。
- **PPL-R07** 顯示名稱：員工是員工名單上的姓名；眷屬是「{員工姓名}_眷屬」，{員工姓名} 是所屬員工的姓名，不加數字；外部貴賓是姓名。
- **PPL-R08** 眷屬的部門是所屬員工的部門；眷屬沒有分機。
- **PPL-R09** 三種類別都可以標注「需要兒童椅」與「素食」，各只記是或否；其他飲食需求寫在備註。兩種標示也會出現在座位圖、桌次詳情與匯出（`seating.md`、`export.md`）。
- **PPL-R10** 只有員工可以標為工作人員。工作人員坐工作人員桌，不佔 30 桌的座位，不算已入座，也不算未入座；工作人員桌最多 10 位。工作人員的眷屬照常坐自己的桌次。工作人員桌的其他規則見 `seating.md`。
- **PPL-R11** 備註選填，只給承辦人看。

### 3.2 連動

- **PPL-R12** 員工名單改了已報名員工的姓名、部門、組別或分機，參與人員與座位圖立即跟著變，包括這位員工的眷屬的顯示名稱與部門。
- **PPL-R13** 眷屬的所屬員工改變時，眷屬的顯示名稱與部門跟著新的所屬員工。
- **PPL-R14** 取消報名：員工從參與人員移除，眷屬一併移除；兩人原本的座位（包括工作人員桌的位置）空出來。員工名單不變，這位員工之後可以再加入尾牙。
- **PPL-R15** 刪除眷屬或外部貴賓：從參與人員移除，原本的座位空出來，同桌其他人的順序不變。
- **PPL-R16** 在員工名單刪除已報名的員工時，一併取消報名、移除眷屬並空出座位（流程見 `employees.md`）。
- **PPL-R17** 移出桌次只改變入座狀態，不刪除人員。
- **PPL-R18** 新增、編輯、刪除、加入尾牙、取消報名都在操作完成時立即儲存（`README.md`），而且不能復原。

### 3.3 參與人員頁

- **PPL-R19** 清單列出全部參與人員；員工名單上沒報名的員工不會出現。
- **PPL-R20** 預設排序：依部門排列，外部貴賓排在最後；眷屬緊接在所屬員工的下一列。部門順序與部門內的順序見待確認 PPL-Q13。
- **PPL-R21** 搜尋列出顯示名稱、分機、部門或單位／頭銜包含關鍵字的人員。眷屬的顯示名稱含所屬員工的姓名，所以用員工姓名搜尋時，員工與眷屬都會列出。
- **PPL-R22** 篩選預設都是「不限」。搜尋與各篩選同時作用，只列出同時符合全部條件的人員。
- **PPL-R23** 類別篩選只列出該類別的人員。
- **PPL-R24** 部門篩選的選項來自員工名單的部門。選了部門時，列出該部門的員工，以及所屬員工在該部門的眷屬；外部貴賓不符合任何部門。
- **PPL-R25** 入座狀態篩選：「已入座」是坐在 30 桌其中一桌的人；「未入座」是不在任何桌次、也不是工作人員的人；「工作人員」是工作人員。
- **PPL-R26** 桌次篩選的選項依 A1～A15、B1～B15 排列，只列場上的桌（不列「未放桌」的位置與暫存區的桌，D-027）；選「{桌號}」時，只列出坐在那一桌的人；工作人員與未入座的人（含暫存區的桌上的人）不符合。入座狀態篩選的「未入座」包含暫存區的桌上的人。
- **PPL-R27** 套用的每一項篩選，以 Badge `outline` 按鈕顯示在工具列下方，按下即把那一項改回「不限」。「清除篩選」把全部篩選改回「不限」，不影響搜尋框。
- **PPL-R28** 每頁 20 列。總頁數 7 頁以內時列出全部頁碼；超過 7 頁時只列第一頁、最後一頁與目前頁附近的頁碼，中間用省略號。摘要與按鈕文案見 `README.md`。
- **PPL-R29** 類別欄：員工顯示「員工」；眷屬有稱謂時顯示「眷屬（{稱謂}）」，沒有時顯示「眷屬」；外部貴賓顯示「外部貴賓」。
- **PPL-R30** 部門或單位欄：員工顯示員工名單上的部門，眷屬顯示所屬員工的部門，外部貴賓顯示單位／頭銜。
- **PPL-R31** 分機欄：員工顯示分機；眷屬、外部貴賓與沒有分機的員工顯示「—」。
- **PPL-R32** 標示欄：需要兒童椅顯示「兒童椅」徽章，素食顯示「素食」徽章，兩項都有就並排，都沒有顯示「—」。顯示名稱旁不標兒童椅與素食；外部貴賓在顯示名稱旁加「貴賓」徽章；眷屬不加徽章。
- **PPL-R33** 桌次欄：已入座顯示「{桌號}」，未入座顯示「未入座」，工作人員顯示「工作人員」，在暫存區的桌上顯示「暫存」（D-027）。按「{桌號}」開啟座位安排（`/?table={桌號}`，例如 `/?table=A1`），並顯示那一桌的桌次詳情（`seating.md`）；按「暫存」開啟座位安排，並顯示那張暫存的桌的詳情。
- **PPL-R34** 列操作的項目依第 2.2 節的表：已入座顯示「移至其他桌次…」「移出桌次」，未入座顯示「入座…」；員工用「取消報名」，眷屬與外部貴賓用「刪除」；工作人員只有「編輯」「取消報名」。
- **PPL-R35** 「入座…」與「移至其他桌次…」開啟選擇桌次對話框（`seating.md`）。
- **PPL-R36** 「移出桌次」把人員變成未入座，Sonner 顯示「已把 {顯示名稱} 移出 {桌號} 桌。」並帶「復原」；按「復原」回到原本的桌次（復原規則見 `seating.md`）。
- **PPL-R37** 「取消報名」先開確認對話框。按「確認取消報名」依 PPL-R14 執行，Sonner 顯示「已取消 {姓名} 的報名。」；按「返回」不做任何改變。
- **PPL-R38** 「刪除」先開確認對話框。按「刪除人員」依 PPL-R15 執行，Sonner 顯示「已刪除 {顯示名稱}。」；按「取消」不做任何改變。
- **PPL-R39** 「新增人員」開啟新增人員對話框；「匯入參與人員」開啟匯入參與人員對話框；「匯出座位表」直接下載座位表，不開對話框（`export.md`）。
- **PPL-R40** 空狀態：沒有任何參與人員時顯示「沒有人員」，「前往員工名單」開啟 `/employees`，「新增人員」開啟新增人員對話框。有搜尋字、沒套用篩選而沒有結果時顯示「搜尋無結果」，「清除搜尋」清空搜尋框。有篩選、沒有搜尋字而沒有結果時顯示「篩選無結果」，「清除篩選」同 PPL-R27。兩者都有時見待確認 PPL-Q16。

### 3.4 新增、編輯人員對話框

- **PPL-R41** 對話框先選類別，欄位依類別顯示（第 2.3 節）；換類別時只顯示新類別的欄位。
- **PPL-R42** 員工欄位只能從員工名單選一位，不能手動輸入姓名。可用姓名、分機或部門搜尋；選項顯示「{姓名}（{部門}・分機 {分機}）」，員工沒有分機時依 `README.md` 只顯示部門。同名的員工以部門與分機區分。員工名單上標記為不參加的員工（`employees.md` 的 EMP-R03）照常列出、可以選，選項後面標示「不參加」；加入後變成已報名，不參加的標記清掉（D-014）。
- **PPL-R43** 已報名的員工在員工選項中停用，並加上「・已報名」。
- **PPL-R44** 選好員工後，欄位下方顯示「{部門}・分機 {分機}」；員工沒有分機時只顯示部門（`README.md`）。
- **PPL-R45** 按下新增時這位員工已經報名（例如別人剛把他加入尾牙）：不新增，員工欄位顯示「{姓名} 已經報名了。」；其餘處理依 `README.md` 的多人衝突。
- **PPL-R46** 新增員工時可以勾選「同時加一位眷屬」，勾選後展開眷屬稱謂、眷屬需要兒童椅、眷屬素食。儲存後同時新增一位眷屬，所屬員工是這位員工，Sonner 顯示「已新增 {姓名} 與 1 位眷屬。」。編輯時沒有這個選項。
- **PPL-R47** 編輯員工時，員工欄位唯讀，顯示「{姓名}（{部門}・分機 {分機}）」與說明「姓名、部門與分機請到員工名單修改。」。
- **PPL-R48** 眷屬的所屬員工必填，選項只列已報名的員工，帶部門與分機；可用姓名搜尋，也能用分機搜尋（`README.md`）。選好後顯示「將顯示為「{員工姓名}_眷屬」」。
- **PPL-R49** 所屬員工已經有另一位眷屬時不能儲存，所屬員工欄位顯示「{員工姓名} 已經有一位眷屬，一位員工最多一位。」。編輯眷屬時，這位眷屬自己不算「已經有一位」。
- **PPL-R50** 稱謂與眷屬稱謂是可搜尋的下拉選單，常見選項是配偶、子女、父母、兄弟姊妹。輸入的文字不在選項中時出現「新增稱謂「{輸入文字}」」，按下即以輸入的文字作為稱謂。
- **PPL-R51** 外部貴賓的姓名必填，單位／頭銜選填。
- **PPL-R52** 三種類別都有「需要兒童椅」與「素食」勾選框。
- **PPL-R53** 只有類別是員工時出現「工作人員」勾選框。勾選後隱藏桌次欄位，儲存後員工放進工作人員桌；同時加的眷屬先留在未入座。
- **PPL-R54** 工作人員桌已有 10 位以上時（`seating.md` SEAT-R88，D-018），還不是工作人員的員工不能勾選「工作人員」（停用），並顯示「工作人員桌已滿，請先移出一位。」。已經是工作人員的員工不受影響。
- **PPL-R55** 編輯已入座的員工、改成工作人員：儲存後從原本的桌次移到工作人員桌，原本的座位空出來，眷屬留在原本的桌次；Sonner 顯示「已儲存，{姓名} 已從 {桌號} 桌移到工作人員桌。」。
- **PPL-R56** 新增時有桌次欄位，預設「未入座」；選項是「{桌號} 桌（剩 {k} 位）」，依 A1～A15、B1～B15 排列，只列場上的桌（D-027），已有 10 位以上的桌次停用並標示「已滿」（{k} 最少 0，D-018）。選了桌次時，儲存後人員入座那一桌；留在「未入座」時，之後再安排。
- **PPL-R57** 同時加眷屬並選了桌次：眷屬和員工入座同一桌。那一桌只剩 1 位時，員工入座、眷屬留在未入座，Sonner 顯示「{桌號} 桌只剩 1 位，{姓名}_眷屬先留在未入座。」。
- **PPL-R58** 編輯有眷屬的員工時，類別欄位停用，並以 Alert 顯示「{姓名} 有 {n} 位眷屬，要變更類別請先處理眷屬。」。其他人員編輯時變更類別的做法見待確認 PPL-Q07。
- **PPL-R59** 必填欄位沒填時不能儲存：輸入欄位顯示「請輸入{欄位名稱}。」，下拉欄位顯示「請選擇{欄位名稱}。」。驗證時機與聚焦依 `README.md`。
- **PPL-R60** 儲存成功後關閉對話框：新增顯示「已新增 {顯示名稱}。」，編輯顯示「已儲存」（同時加眷屬與改成工作人員的訊息見 PPL-R46、PPL-R55）。按「取消」或關閉對話框時不儲存任何改變。

### 3.5 從員工名單加入尾牙（EMP-03）

- **PPL-R61** 員工名單的單筆「加入尾牙」開啟新增人員對話框：類別固定為員工且不能改，員工已帶入且不能改；其餘欄位與規則和新增員工相同（PPL-R46、PPL-R52～PPL-R54、PPL-R56、PPL-R57、PPL-R59）；主要按鈕是「加入尾牙」。
- **PPL-R62** 加入成功後 Sonner 顯示「已把 {姓名} 加入尾牙。」，這位員工在員工名單上變成已報名（`employees.md`）。
- **PPL-R63** 在員工名單勾選多位一次加入時，每位員工各新增一位類別為員工的參與人員，只加員工本人、不加眷屬，加入後是未入座；眷屬之後在參與人員補上。畫面與確認對話框見 `employees.md`。

### 3.6 匯入參與人員

依 D-010，匯入的檔案是 Google 表單報名表的原始檔案，不再用自訂範本。表單沒有外部貴賓、桌次與工作人員，這些在畫面上處理。

- **PPL-R64** 匯入的檔案是 Google 表單尾牙報名表匯出的 CSV 原始檔案，和正式版 seed 共用同一套解析（`registration-import.ts`，見 `docs/architecture.md` 的參與人員模組）。對話框沒有「下載範本」。
- **PPL-R65** 檔案必填，只接受 CSV 檔。沒選檔案就按「開始匯入」時，檔案欄位顯示「請選擇要匯入的檔案。」。
- **PPL-R66** 欄位以表頭文字辨認，不看欄位順序。表頭比對前先去掉半形與全形空白，並把相容字元轉成一般字（例如實際表頭「尾⽛」的 `⽛` 視為「牙」）。正規化後的表頭包含下表的文字，就是那一欄（目前假設，見待確認 PPL-Q22）：

  | 欄位 | 表頭包含 | 實際表頭 | 用途 |
  |---|---|---|---|
  | 名字 | 名字 | 您的名字 ( 請填寫本名 ) | 對應員工名單的姓名 |
  | 部門 | 部門 | 部門 | 同名時判斷是哪一位 |
  | 是否參加 | 是否會參加 | 是否會參加本次尾⽛？ | 只收「是」 |
  | 是否攜帶眷屬 | 是否攜帶眷屬 | 是否攜帶眷屬 ？ | 「是」時加一位眷屬 |
  | 是否需要兒童座椅 | 兒童座椅 | 是否需要兒童座椅  ？ | 「是」時眷屬需要兒童椅 |
  | 本人的飲食習慣 | 您的飲食習慣 | 請問您的飲食習慣 | 和下一列任一欄含「素」而且不含「葷」時，員工標素食 |
  | 本人葷素 | 吃葷還是吃素 | 請問您是吃葷還是吃素？ | 同上一列；這一欄可以不存在 |
  | 眷屬的飲食習慣 | 眷屬的飲食習慣 | 攜帶眷屬的飲食習慣 | 含「素」而且不含「葷」時，眷屬標素食 |
  | 備註 | 備註 | 備註 | 寫進員工的備註 |

- **PPL-R67** 其他欄位不讀也不存，包括時間戳記、電子郵件地址、「請填寫不參加尾⽛理由」與表頭是「第 {n} 欄」的欄位。電子郵件與填寫時間不寫進資料庫。
- **PPL-R68** 表頭缺少 PPL-R66 表中任何一欄（「本人葷素」除外）時，整份檔案都不匯入，檔案欄位顯示「檔案欄位和報名表不一致，請上傳 Google 表單匯出的原始檔案。」。
- **PPL-R69** 同一人填了好幾次時，以檔案中最後一列為準，前面的列不處理。對應得到員工名單的，以對應到同一位員工判斷是同一人；對不到的，以名字與部門相同判斷（目前假設，見待確認 PPL-Q24）。
- **PPL-R70** 只收最後一次的是否參加填「是」的人（「是」的判斷見待確認 PPL-Q01）。填其他回答、還沒報名的人不新增，也不算需要處理；已報名的人見 PPL-R82。
- **PPL-R71** 名字對應員工名單的姓名；員工名單上有同名的人時，再用部門判斷。名字與部門比對前同樣去掉空白、把相容字元轉成一般字。對不到員工名單，或同名而部門也判斷不出是哪一位的人，不匯入，列為需要處理（待確認 PPL-Q03）。
- **PPL-R72** 還沒報名的員工：新增一位類別為員工的參與人員；本人的飲食習慣或葷素欄含「素」而且不含「葷」時標素食；表單的備註寫進這位員工的備註。新增的人是未入座，不是工作人員，員工本人不標兒童椅。部門與分機仍以員工名單為準（PPL-R02）。員工名單上標記為不參加的員工也照這條新增，不參加的標記清掉，不列為需要處理（D-014）。填「不參加」的員工不會因匯入被標記為不參加。
- **PPL-R73** 是否攜帶眷屬填「是」時，同時新增一位眷屬：所屬員工是這位員工，稱謂空白，未入座。是否需要兒童座椅填「是」時，眷屬需要兒童椅；眷屬的飲食習慣含「素」而且不含「葷」時，眷屬標素食。沒有攜帶眷屬時不看兒童座椅欄（目前假設，見待確認 PPL-Q25）。
- **PPL-R74** 匯入完成後，對話框顯示「已匯入 {n} 位，{m} 筆需要處理。」。{n} 是這次新增或更新的報名員工人數，眷屬不另外計算；{m} 是需要處理的人數。{m} 大於 0 時顯示「下載錯誤清單」，下載需要處理的人與原因（目前假設，見待確認 PPL-Q06）。
- **PPL-R79** 匯入不會新增外部貴賓，也不改任何人的座位與工作人員。
- **PPL-R80** 重複匯入（承辦人之後重新匯出表單，補上新報名的人）時，新的報名者依 PPL-R72、PPL-R73 新增。已報名的員工不重複新增，依這次的表單更新員工的素食，以及眷屬的兒童椅與素食；備註只在系統裡沒有備註時才填入表單的備註，已有備註時保留；座位與工作人員不動（目前假設，見待確認 PPL-Q20）。
- **PPL-R81** 重複匯入時，表單填攜帶眷屬、系統裡這位員工還沒有眷屬，就補一位眷屬（同 PPL-R73，未入座）（目前假設，見待確認 PPL-Q20）。
- **PPL-R82** 已報名的員工最後一次填不參加時，不自動取消報名，資料與座位都不變，列為需要處理，原因說明要手動取消報名（目前假設，見待確認 PPL-Q20）。
- **PPL-R83** 系統裡這位員工已有眷屬、表單最後一次填沒有攜帶眷屬時，不刪除眷屬，列為需要處理，原因說明要手動刪除；這位員工的其他資料照 PPL-R80 更新（目前假設，見待確認 PPL-Q20）。
- **PPL-R84** 表單裡沒有的參與人員（例如在畫面上加入的員工、外部貴賓）不受匯入影響。
- **PPL-R85** 需要處理的人不匯入，其餘照常匯入並立即儲存。

### 3.7 手機版

- **PPL-R75** 視窗 767 px 以下時，表格改為堆疊卡片，每張卡片顯示顯示名稱、類別、部門或單位、分機、標示、桌次，不顯示備註，並保留列操作。
- **PPL-R76** 視窗 767 px 以下時，工具列的項目各自滿版，依序堆疊：搜尋、類別、部門、入座狀態、桌次。
- **PPL-R77** 視窗 767 px 以下時，Dialog 與 Alert Dialog 寬度隨視窗縮小，按鈕滿版堆疊，主要按鈕（確認鈕）在上。

### 3.8 只能檢視
